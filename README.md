# 本地图片点评管理器 (comment-photos)

一个 Chrome 扩展（Manifest V3），让你在浏览器里**管理本地图片文件夹并撰写点评**。点评保存在本地，不修改、不上传任何原图。

## 创意来源

电脑里积攒了几万张照片——旅行、美食、日常……想给它们写点文字记录、留个备注，却一直没有顺手的工具：

- 在线图床 / 相册会把图片传上服务器，隐私和存储都不可控；
- 命名系统（IMG_20240101.jpg）信息量太少，靠文件名做备注既慢又丑；
- 桌面软件笨重，浏览、点评、筛选来回切换很麻烦。

这个项目的核心思路是 **「点评属于文件夹，而不属于文件」**：

> 在一个本地文件夹里放一份 `comments.json`，记录每张图片的标题、时间与点评文字。图片本身永远不动，点评跟着图片走——即使你重命名、移动甚至复制了图片，点评也能通过文件内容（SHA-256 指纹）自动匹配回来。

## 能完成的事情

- 📁 **选择本地文件夹**：一键授权后递归扫描文件夹内所有图片（支持 jpg / jpeg / png / webp / bmp / gif）。
- ✍️ **图片点评**：为每张图填写标题、拍摄时间与点评文字，表格化浏览，已点评 / 未点评状态一目了然。
- 🔒 **纯本地存储**：所有数据只写进所选文件夹里的 `comments.json`，绝不触碰原图，也不上传任何内容。
- 🔄 **点评防丢失**：通过 SHA-256 文件指纹匹配，重命名、移动图片后点评依旧跟得回来，并自动同步新路径。
- ✨ **AI 智能点评**（可选）：接入智谱 GLM-4.6V-Flash 视觉模型，一键生成点评文字，可自定义提示词。仅在主动点击时把**当前选中图片**发送给 AI，返回的文字同样只保存在本地。
- 🗂 **筛选与进度**：按「全部 / 已点评 / 未点评」筛选，扫描大量图片时显示实时进度。
- 🔑 **记住授权**：用 IndexedDB 持久化文件夹句柄，下次打开免重复授权。

## 安装

1. 打开 `chrome://extensions`；
2. 开启右上角「开发者模式」；
3. 点击「加载已解压的扩展程序」，选择本项目目录；
4. 点击工具栏中的扩展图标，打开管理器。

## 使用

1. 点击「📁 选择文件夹」，授权一个本地图片文件夹；
2. 应用会递归扫描并展示所有图片；
3. 点击任意图片，填写标题 / 时间 / 点评并保存（`Ctrl+Enter` 保存，`Esc` 取消）；
4. （可选）在「✨ AI 设置」中粘贴智谱开放平台的 API Key，即可一键生成点评。

### 开启 AI 点评

1. 前往 [智谱开放平台 GLM-4.6V-Flash 免费申请页](https://docs.bigmodel.cn/cn/guide/models/free/glm-4.6v-flash) 申请免费 API Key；
2. 在扩展的「✨ AI 设置」中填入 Key（密钥仅保存在 Chrome 本地存储），点击「测试连接」验证；
3. 打开某张图片，点击「✨ AI 点评」自动生成点评文字。

## 数据说明

| 内容 | 存放位置 |
| --- | --- |
| 点评数据（标题 / 时间 / 文字 / 文件指纹） | 所选文件夹内的 `comments.json` |
| 文件夹授权句柄 | Chrome IndexedDB（`local-image-comments`） |
| AI 设置（API Key / 提示词） | Chrome `storage.local` |

> `comments.json` 采用版本化结构（`version: 1`），可与图片一起备份、迁移，重装扩展不丢点评。

## 为什么是浏览器扩展，而不是 Web 网页或桌面应用？

| 维度 | 本项目（Chrome 扩展） | Web 网页 | 桌面应用（Electron/Tauri） |
| --- | --- | --- | --- |
| 本地文件访问 | ✅ 可持久化文件夹授权，重启免重选 | ⚠️ File System Access API 授权会随会话失效，需频繁重授权 | ✅ 完全访问 |
| 隐私 | ✅ 图片与点评全在本地，无服务器 | 无后端则同上；有后端就得上传图片 | ✅ 全本地 |
| 部署成本 | ✅ 零部署，`chrome://extensions` 一键加载 | ❌ 需要服务器 / 域名 / 数据库 | ⚠️ 需要打包、签名、更新分发 |
| 跨平台 | ✅ 全平台 Chrome 即用 | ✅ | ⚠️ 分平台打包 |
| 启动开销 | ✅ 无体积，随点随开 | ✅ | ❌ 需要安装、常驻进程 |
| 与浏览器工作流集成 | ✅ 工具栏图标、后台 service worker | ⚠️ 依赖标签页常开 | ❌ 独立于浏览器 |
| 能力上限 | ⚠️ 受浏览器安全沙箱限制 | ⚠️ 同左，且更难拿本地权限 | ✅ 能力最强 |

**核心取舍：** 这个工具的立身之本就是「点评留在本地、不碰原图、不建服务器」。扩展是唯一满足这一点且**零部署成本**的形态——它借助 File System Access API + IndexedDB 拿到"打开即授权、重启不丢"的本地文件夹能力，又没有网页端"每次重授权"的麻烦。桌面应用能力最强，但打包、签名、跨平台分发对一个小而美的工具来说属于过度投入；网页端则要么失去本地性，要么受制于会话级授权。因此扩展是"本地优先、隐私优先"前提下投入产出比最高的形态。

## 隐私

- 图片**不会**上传，除非你主动点击「✨ AI 点评」；
- 点评文字只写入本地 `comments.json`；
- API Key 只保存在本机浏览器，可随时在设置中清空以停用 AI 功能；
- 扩展仅请求 `storage` 权限，AI 调用使用可选的主机权限按需申请。

## 技术栈

- Chrome Manifest V3（service worker + action）
- File System Access API（读取本地文件夹）
- IndexedDB（持久化授权句柄）
- SHA-256 文件指纹匹配（Web Crypto）
- 智谱 GLM-4.6V-Flash 视觉模型（可选）
- 原生 ES Modules，无第三方依赖

## 目录结构

```
├── manifest.json          # 扩展清单（MV3）
├── background.js          # 后台 service worker
├── icons/                 # 扩展图标
├── app/
│   ├── index.html         # 主界面
│   ├── css/style.css      # 样式
│   └── js/
│       ├── app.js         # 界面逻辑
│       ├── scan.js        # 递归扫描图片
│       ├── hash.js        # SHA-256 文件指纹
│       ├── match.js       # 点评与图片匹配（重命名/移动追踪）
│       ├── store.js       # comments.json 读写
│       ├── db.js          # IndexedDB 授权句柄
│       ├── ai.js          # 智谱 AI 点评
│       └── thumbs.js      # 缩略图
```
